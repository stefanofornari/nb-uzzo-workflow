## project/US-000004 — Hide Meta and Temporary Files from the Knowledge Base Tree

### User Story

```
AS A Uzzo workflow user
I WANT meta, OS, editor, and temporary files to be hidden from the knowledge base tree
SO THAT I can focus on the actual knowledge base content
```

#### Status
DONE

#### Dependencies
- project/US-000001

#### Technical Context & Constraints
* **Target System**: NetBeans IDE module (`nbm`), Projects view tree.
* **Toolchain / Rules**: Java 17, NetBeans Platform `RELEASE280`, Maven, JUnit 5.
* **Phase**: Delivered — filtering is applied by the tree children wrapper.
* The rules apply to both files and folders, at any depth, and apply only to the tree: the entries remain on disk.
* Name matching is case-insensitive so that Windows metadata files are hidden on every platform.

### Acceptance Criteria

```gherkin
Scenario: Hidden entries are omitted
  Given the knowledge base contains ".gitkeep", ".gitignore", and a ".git" folder
  When  the knowledge base tree is displayed
  Then  none of those entries is listed

Scenario: OS metadata is omitted
  Given the knowledge base contains "Thumbs.db", "desktop.ini", and ".DS_Store"
  When  the knowledge base tree is displayed
  Then  none of those entries is listed

Scenario: Editor backup and swap files are omitted
  Given the knowledge base contains "notes.md~", ".notes.md.swp", "notes.md.swo", ".#notes.md", and "#notes.md#"
  When  the knowledge base tree is displayed
  Then  none of those entries is listed
  And   "notes.md" is still listed

Scenario: Temporary and backup files are omitted
  Given the knowledge base contains "draft.md.tmp" and "draft.md.bak"
  When  the knowledge base tree is displayed
  Then  neither entry is listed

Scenario: Filtering applies at every depth and to folders
  Given a nested folder contains ".gitkeep", "Thumbs.db", and a folder named "cache.tmp"
  When  the knowledge base tree is expanded to that folder
  Then  the ignored entries are not listed at that level

Scenario: Regular content is preserved
  Given the knowledge base contains "README.md", "v1.2-notes.md", and "my.notes.md"
  When  the knowledge base tree is displayed
  Then  all of them are listed

Scenario: Matching is case-insensitive
  Given the knowledge base contains "THUMBS.DB" and "DRAFT.MD.BAK"
  When  the knowledge base tree is displayed
  Then  neither entry is listed
```
