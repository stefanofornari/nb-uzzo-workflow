## project/US-000001 — Show the Uzzo Knowledge Base in the Projects View

### User Story

```
AS A Uzzo workflow user
I WANT the project's uzz folder to appear as an Uzzo Knowledge Base node in the Projects view
SO THAT I can reach the knowledge base from the same place as the rest of my Maven project
```

#### Status
DONE

#### Dependencies
- None

#### Technical Context & Constraints
* **Target System**: NetBeans IDE module (`nbm`), logical view of Maven projects.
* **Toolchain / Rules**: Java 17, NetBeans Platform `RELEASE280`, Maven, JUnit 5.
* **Phase**: Delivered — the module already implements this capability.

### Acceptance Criteria

```gherkin
Scenario: Knowledge base folder is present
  Given a Maven project whose root contains a top-level "uzz" folder
  When  the user opens the project's logical view
  Then  an "Uzzo Knowledge Base" node is shown for the "uzz" folder

Scenario: Project has no knowledge base folder
  Given a Maven project whose root has no top-level "uzz" folder
  When  the user opens the project's logical view
  Then  no "Uzzo Knowledge Base" node is shown

Scenario: Knowledge base folder is created while the project is open
  Given an open Maven project without a top-level "uzz" folder
  When  the user creates the top-level "uzz" folder
  Then  the "Uzzo Knowledge Base" node appears without reloading the project

Scenario: Knowledge base folder is deleted while the project is open
  Given an open Maven project whose root contains a top-level "uzz" folder
  When  the user deletes or renames that folder
  Then  the "Uzzo Knowledge Base" node is removed from the logical view

Scenario: Knowledge base node exposes the folder contents
  Given the "Uzzo Knowledge Base" node is shown
  When  the user expands it or invokes folder actions
  Then  its children are the contents of the "uzz" folder and the actions apply to that folder
```
