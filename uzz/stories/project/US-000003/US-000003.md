## project/US-000003 — Refresh Knowledge Base Content from the Project View

### User Story

```
AS A Uzzo workflow user
I WANT a Refresh Knowledge Base action on the Uzzo Knowledge Base node
SO THAT content created or deleted outside NetBeans becomes visible without restarting the IDE
```

#### Status
DONE

#### Dependencies
- project/US-000001

#### Technical Context & Constraints
* **Target System**: NetBeans IDE module (`nbm`), Projects view context menu.
* **Toolchain / Rules**: Java 17, NetBeans Platform `RELEASE280`, Maven, JUnit 5.
* **Phase**: Delivered — the module already implements this capability.

### Acceptance Criteria

```gherkin
Scenario: Refresh action is available
  Given the "Uzzo Knowledge Base" node is shown
  When  the user opens its context menu
  Then  a "Refresh Knowledge Base" action is offered

Scenario: New content created outside NetBeans
  Given the knowledge base tree is expanded to a folder
  When  an external tool creates a new folder or file in that folder
  And   the user invokes "Refresh Knowledge Base"
  Then  the new content is shown without restarting the IDE

Scenario: Content deleted outside NetBeans
  Given a knowledge base file is shown in the tree
  When  an external tool deletes that file
  And   the user invokes "Refresh Knowledge Base"
  Then  the file is removed from the tree

Scenario: Empty knowledge base
  Given the knowledge base contains no files
  When  the user invokes "Refresh Knowledge Base"
  Then  the action completes without errors
  And   the tree remains empty
```
