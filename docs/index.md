# Uzzo Workflow for NetBeans
{: .fs-9 }

A NetBeans plugin that brings the AI-based Uzzo Development Workflow into your IDE.
{: .fs-6 .fw-300 }

[Install it](instructions){: .btn .btn-primary .fs-5 .mb-4 .mb-md-0 .mr-2 }
[View on GitHub](https://github.com/stefanofornari/nb-uzzo-workflow){: .btn .fs-5 .mb-4 .mb-md-0 }

---

[Uzzo Workflow](https://stefanofornari.github.io/uzzo-workflow/) is an AI-based
software development workflow for product owners and product engineers. It is
built on three interactive activities: **scoping** an idea until its boundaries
are solid, generating INVEST-compliant **user stories**, and **coding** each
story against the scope and your coding standard.

All of that information lives in the **Uzzo Knowledge Base**, a plain-Markdown
`uzz/` folder in your project. This plugin brings it into the NetBeans project
tree and keeps it in sync with the file system.

## What you get

- An **Uzzo Knowledge Base** node in your project, showing the `uzz` folder
- Documents from the knowledge base open in their own editor deck, on the right
- One-click **initialization** of a knowledge base in a Maven project
- **Repair** and **refresh** actions that keep it complete and up to date

See [Features](features) for the details, or go straight to the
[instructions](instructions) to install the plugin and create your first
knowledge base.
